# Weather App

A simple desktop weather application built with Python and Tkinter.

## Overview

This project allows the user to enter a city name and retrieve its current weather information. It uses Open-Meteo for geocoding and current weather data, and presents the result through a simple graphical interface.

## Features

- City name input
- Current temperature display
- Weather-condition description in Persian
- Persian graphical user interface
- Enter-key support for checking the weather
- Basic error and status messages

## Technologies

- Python
- Tkinter
- Requests
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## Run

Install the required dependency:

```bash
pip install requests
```

Then run:

```bash
python weather-app.py
```
